# PurchaseOrderApp Frontend

React and TypeScript frontend for the PurchaseOrderApp take-home project.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run test
```

The frontend expects the API base URL from app configuration and defaults to the local API used by Docker Compose.

For full setup, assumptions, self-review, and AI usage notes, see the root `Readme.md`.
